# 📌 About Task 4

This project was completed as part of the **DevOps Internship - Task 4**.

The main objective of this task is to understand and implement **Git and GitHub version control best practices**.

The task focuses on creating a Git repository, connecting it with GitHub, creating different branches, developing features, using Pull Requests for merging, maintaining a proper README file, using `.gitignore`, creating Git tags, and documenting the complete workflow using Markdown.

---

# 🎯 Task Objectives

The objectives of Task 4 are:

- Initialize a Git repository
- Push the project to GitHub
- Create `main`, `dev`, and `feature` branches
- Use Pull Requests for merging
- Create a proper `README.md`
- Use `.gitignore`
- Create and use Git tags
- Document the complete task using Markdown
